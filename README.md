# ぷくともちの 温泉旅行

ぷくともちが おんせんまちを たびする、ぜん11ページの えほんです。スマートフォンでは「うえに おおきなえ、したに おはなし」の たてわりで たのしめます。

## おはなし

1. おんせんりょこう
2. でんしゃで しゅっぱつ
3. おんせんまちに とうちゃく
4. ほかほか おんせんまんじゅう
5. りょかんの おへや
6. ゆかたに きがえよう
7. たっきゅう
8. おそとの おんせん
9. りょかんの ごちそう
10. よるの くつろぎ
11. たびの おもいで

## あそびかた

- 「まえへ」「つぎへ」ボタン、ページドット、キーボードの左右キーでページをめくります。
- スマートフォンでは、えほんを左右にスワイプしてページをめくれます。
- 最後のページの「おもいでを みる」から、6つの場面をえらべます。
- `#page-bath` のように、ページのURLを直接ひらけます。
- 音はありません。

## ひらく

静的ファイルとして配信します。Pythonがある場合は次のコマンドで確認できます。

```powershell
python -m http.server 4173
```

ブラウザで `http://127.0.0.1:4173/` を開いてください。

公開前のファイル確認：

```powershell
node scripts/check-static.mjs
```
